# CASA 1.3.3 — Out of band verifier shall be securely random

**Source:** ADA Web App Test Guide v1.0 (10 Oct 2024), AL1 evidence + verification.  
**ASVS:** 2.7.6  
**Date:** 28 Aug 2026  

## ADA AL1 evidence

1. List external user authentication services.
2. If proprietary, describe the algorithm used to generate initial authentication codes.

Verification: ADA-approved IdP **or** generation shall be securely random (impossible for an attacker to predict or manipulate).

## External services

| Service | OOB verifiers | ADA-approved IdP? |
| --- | --- | --- |
| **Supabase Auth (GoTrue)** | Password-reset recovery email / Email OTP; signup confirmation; TOTP MFA secret | **Not claimed.** |
| **Google OAuth** | Not an email/SMS login verifier | Out of scope for 1.3.3. |

No SMS OTPs. Invite-token generation is documented here because it is the only OOB-style code Velvet Elves mints itself; lifetime/single-use stay on 1.1.2 / 1.3.2.

## Generation process

Velvet Elves does **not** generate password-reset codes. `POST /users/password-reset/request` calls `supabase.auth.reset_password_email` and returns 202. The recovery token lives in the vendor email. Confirm (`POST /users/password-reset/confirm`) accepts that vendor token or PKCE auth code. Application tables do not store a reset OTP.

**GoTrue Email OTP / recovery**

- Auth Email **OTP length = 8 digits** (owner-captured dashboard; same panel as 1.3.1). That is a vendor-generated numeric OTP, not a sequential counter we increment.
- Recovery emails use a hashed GoTrue token in the link, not a short code the app invents. We do not claim a specific GoTrue CSPRNG API or source file.
- Opening `/reset-password` without a valid token cannot set a password.

**Invite activation token (proprietary, CSPRNG)**

- `InvitationRepository.create` sets `token = uuid.uuid4().hex` (32 hex characters).
- CPython `uuid.uuid4()` draws from `os.urandom` (122 random bits after RFC 4122 version/variant bits). An attacker cannot predict the next invite token from previous ones.

**TOTP MFA**

- The shared secret is returned by GoTrue `POST /auth/v1/factors` (`enroll_totp`). Velvet Elves does not mint the TOTP secret. Authenticator codes follow RFC 6238 (30-second step).
